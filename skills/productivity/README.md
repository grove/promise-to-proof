# Productivity Skills

Skills for carrying an agreed outcome from design through implementation,
acceptance verification, and CI repair. Each works independently.

- [`interrogate`](./interrogate/SKILL.md): Stress-test a proposal, preserve agreed requirements, and record authorized changes.
- [`acceptance-matrix`](./acceptance-matrix/SKILL.md): Turn promises into stable requirement IDs, observable results, and concrete evidence plans.
- [`prove`](./prove/SKILL.md): Reconcile every requirement with independent evidence and report `PROVEN` or `NOT PROVEN`.
- [`fix-pr`](./fix-pr/SKILL.md): Repair failed PR workflows without weakening checks or promises. `FIXED` establishes CI repair, not full acceptance proof.

See the [workflow and handoff rules](../../README.md) for verdict meanings,
authorization boundaries, and optional integrations.
