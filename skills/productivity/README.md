# Productivity Skills

General workflow and productivity skills.

- [**`acceptance-matrix`**](./acceptance-matrix/SKILL.md) — Turn a spec, ticket, or conversation into stable, proof-ready acceptance rows.
- [**`interrogate`**](./interrogate/SKILL.md) — Let the user interrogate the agent's understanding, proposal, design, or reasoning until they are satisfied it holds up.
- [**`prove`**](./prove/SKILL.md) — Post-implementation verification skill to prove an issue is resolved with independent evidence, hunting counterexamples and repairing gaps until proven.
