## Out of scope

- Completing issue #46's migration of contracts, reports, publication records, or final durable metadata out of source Git.
- Reopening or expanding issue #38; preserve its local-versus-durable boundary, evidence retention, and validated cleanup behavior.
- Requiring multiple repositories, branches, or worktrees for ordinary delivery, or requiring users to manage them.
- A database, cloud artifact service, mandatory remote backend, default push/publication, source-repository commit authority, or automatic Git history rewrite.
- Incremental verification, targeted re-review, or other future verification semantics.
