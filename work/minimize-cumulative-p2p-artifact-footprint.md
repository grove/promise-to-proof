# Acceptance contract: Minimize cumulative Promise to Proof artifact footprint

Contract revision: v2
Source: [Imported issue #38](../specs/minimize-cumulative-p2p-artifact-footprint-source.md)

Intended outcome: Promise to Proof preserves an exact, evidence-backed delivery record while keeping temporary execution and recovery data local and removing it after a validated successful delivery.

## Out of scope

- Database, cloud artifact service, permanent external artifact store, or generic deduplication system.
- Automatic Git history rewriting, changes to acceptance or merge gates, weakening verification, or new publication and merge authority.
- Implementing the issue #35 experience-capture feature, automatic learning promotion, or automatic project-policy changes.
